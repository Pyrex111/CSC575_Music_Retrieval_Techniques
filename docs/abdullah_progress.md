## Validation results

The batch rendered `4 × (source + B0 + B1 + M) + 1` files. That is **five references and 12 comparison WAVs**. FFprobe confirmed stereo 16-bit PCM at **44,100 Hz** and the expected frame count for every file. All 17 file hashes matched the render record. Output loudness ranged from **−23.01 to −22.99 LUFS**, within the **±0.25 LU** tolerance around −23 LUFS. The highest measured true peak was **−10.76 dBTP** against the −2 dBTP ceiling. [Render results](../results/abdullah_progress/results.json) · [Independent checks](../results/abdullah_progress/verification.json)

The first rendering pass showed that instrument release tails differed across methods. The recorded run aligns each WAV to the MIDI endpoint plus a half-second tail with a short fade. All four methods share the same duration within each matched case. The 32-second development excerpts produce 32.5-second WAVs and the 48-second verification excerpts produce 48.5-second WAVs. The fifth reference is a 16-bar, 96 BPM fixture with a 40-second MIDI duration and a 40.5-second WAV. [Per-file timing table](../results/abdullah_progress/summary.md)

The recorded run used an Ubuntu 24.04 x86-64 environment on an Intel Xeon Platinum 8573C with nine logical CPUs visible. Synthesis took **0.214–0.715 seconds per WAV**, with a **0.457-second median**, rounded to milliseconds. The sum of per-file processing times, including alignment, loudness adjustment, and verification, was **73.011 seconds**. These timings describe the recorded environment and settings. [Recorded environment and timings](../results/abdullah_progress/results.json)

A repeat render of `development_rock/source` produced the same WAV hash. Missing input, truncated MIDI, and silent MIDI probes returned errors without creating outputs. The two integration tests also passed. [Verification record](../results/abdullah_progress/verification.json) · [Test source](../tests/test_abdullah_rendering.py)

Reproduce the integration tests after following the setup instructions. Set `CSC575_TEST_SOUNDFONT` and `CSC575_TEST_FLUIDSYNTH` when using different install paths.

```bash
python -m unittest discover -s tests -p 'test_abdullah_rendering.py' -v
```
